testovací repozotář

git clone - naklonuje remote depositar z githubu do PC
git status - ukáže v jaké stavu jsou změny v termninálu - souboru (modefied)
git diff - ukaze nam presne změny soubouru (zeleně)
git add - zastaguju - do stavu stage - připraveno k uložení
git add. -  zastaguje všechnyzměněné soubory
git commit - m "zpráva" musí tam být popsaná zprava proč se změna udělala, uloženo u sebe v PC
git push - pošle zpět zěmny na github depositář
